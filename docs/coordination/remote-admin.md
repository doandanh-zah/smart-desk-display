# Handoff Remote Admin · 13/11/2026

## Đã làm

- Backend trong `remote-admin/`, [hợp đồng v1](remote-admin-contract.md), [hướng dẫn cấu hình và build](../../remote-admin/README.md). Tách quyền browser và device; browser dùng mật khẩu scrypt có salt, session Redis 8 giờ, cookie Secure/HttpOnly/SameSite=Strict, Origin và CSRF, logout thu hồi session. Rate limit Redis 6 lần mỗi IP và 30 lần toàn hệ thống trong 15 phút, chặn trước KDF.
- ESP32 chủ động HTTPS tới `POST /api/device/sync`. Hash token riêng giới hạn ở route sync. Timestamp ±90 giây, nonce dùng một lần, snapshot chỉ giữ trường cho phép. Lệnh display, message, pomodoro và config giới hạn trường. Redis Lua đảm bảo xếp hàng/ACK nguyên tử; mỗi lần chỉ một lệnh, TTL 90 giây, kết quả/idempotency 24 giờ. Firmware sở hữu journal NVS và serial provisioning.
- Project riêng `lilzahs-projects/smart-desk-remote-admin`, Hobby, Node 22.x. `desk.thezah.space` đã gắn và Vercel verify xác nhận cấu hình hợp lệ; không cần thay DNS. Production [deployment READY](https://vercel.com/lilzahs-projects/smart-desk-remote-admin/Agedv32ee3QgFqf9QhAiD4wP5J2z) chạy chế độ khóa. Không mở port nhà và không sửa proxy GitHub hiện có.
- Đã thêm biến Production `ADMIN_ORIGIN` và `DEVICE_TOKEN_SHA256` qua stdin. Token ngẫu nhiên để provisioning nằm trong `.dev/remote-rollout/device.token`, mode 0600, bên ngoài thư mục deploy. Hardware owner đọc bằng luồng trực tiếp từ file tới USB, tránh ghi nội dung vào output/log. Token chưa nạp vào ESP32 trong session này.

## Để mở khóa

1. Chủ tài khoản [chấp nhận điều khoản Upstash Marketplace](https://vercel.com/lilzahs-projects/~/integrations/accept-terms/upstash?source=cli). CLI đã dừng ở `integration_terms_acceptance_required` và chưa tạo Redis. Sau khi xác nhận, chạy lại ở staging đã link: `npx --yes vercel@65.15.0 integration add upstash/upstash-kv --billing-plan free --meta primaryRegion=iad1 --meta autoUpgrade=false --meta prodPack=false --meta eviction=false --name smart-desk-remote-store --environment production --no-env-pull --scope lilzahs-projects --non-interactive`. Upstash Free hiện có 500.000 lệnh/tháng; 20 giây/lần tương đương khoảng 134.000 lần gọi sync/31 ngày. Xác nhận quota sau khi đo usage, giữ auto-upgrade tắt. [Upstash Redis pricing](https://upstash.com/pricing/redis)
2. Chủ tài khoản chạy `source .dev/env.sh && node remote-admin/scripts/password-hash.mjs --copy` trong Terminal để chọn mật khẩu. Lưu hash vào `ADMIN_PASSWORD_HASH` kiểu Sensitive, môi trường Production, tại [Vercel Environment Variables](https://vercel.com/lilzahs-projects/smart-desk-remote-admin/settings/environment-variables). Chỉ gửi xác nhận đã lưu.
3. Stage frontend mới nhất, redeploy Production và kiểm tra login/logout/rate limit trên canonical. Hardware owner flash firmware remote rồi cấp token qua USB. Nghiệm thu thật yêu cầu online snapshot, lệnh áp dụng + ACK, stale/offline khi ngắt cloud và LAN vẫn phản hồi.

## PIN sáu chữ số

- Script `remote-admin/scripts/password-hash.mjs --copy` nhận PIN đúng sáu chữ số ASCII, giữ nguyên số 0 đầu. Mật khẩu dài ít nhất 14 ký tự và tối đa 256 byte vẫn dùng được. Script xác nhận hai lần bằng nhập ẩn và giữ định dạng hash `scrypt-v1` hiện tại. Giá trị dán vào Vercel là hash do script sao chép.
- Giữ giới hạn Redis hiện tại, tối đa 6 lần thử/IP và 30 lần thử toàn hệ thống trong 15 phút, kiểm tra trước scrypt. Định dạng hash chung không phân biệt PIN với mật khẩu dài, nên giới hạn riêng cho PIN sẽ cần thay đổi cấu hình xác thực. PIN sáu chữ số có không gian nhỏ hơn mật khẩu dài. Gateway tiếp tục giữ cookie, Origin và CSRF hiện có.
- Kiểm tra terminal PTY xác nhận PIN có số 0 đầu và mật khẩu dài tạo hash tương thích, input không echo, PIN thiếu ký tự, chữ số Unicode, ký tự chữ hoặc dấu cách bị từ chối. Bộ test backend đạt 11/11 với Redis local thật. Hai instance gateway chia sẻ cả giới hạn theo IP lẫn toàn hệ thống. Đã xác nhận PIN đúng đăng nhập, bỏ số 0 đầu hoặc đổi một chữ số trả 401, và PIN đúng vẫn bị chặn 429 sau khi hết lượt. Log `.dev/logs/remote-admin-pin-tests.log`.
- Không cần đổi frontend để nhập PIN. Contract giữ `password` là chuỗi và bàn giao nhãn tùy chọn cho 04. Script đã sẵn để chủ tài khoản tự tạo hash và thay `ADMIN_PASSWORD_HASH` Sensitive Production. Chưa deploy hay thử PIN trên production. Sau khi xác nhận đã lưu, redeploy từ staging của bản admin đã nghiệm thu rồi smoke active và bàn giao pairing.
