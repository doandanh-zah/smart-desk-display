# Handoff dữ liệu GitHub

- [Hợp đồng v1](github-contract.md) đã chốt schema proxy và interface C++. [Hướng dẫn proxy](../../github-proxy/README.md) có cách chạy fixture, cấu hình Vercel và điền URL trên ESP32.
- Proxy gọi GitHub GraphQL từ Vercel Function. Heatmap dùng 52 cột × 7 hàng UTC, 364 ký tự và năm mức do GitHub phân loại. Tổng tính trong lưới. Streak đếm đến hôm qua nếu hôm nay chưa có đóng góp. Repo public là trường tùy chọn. `GITHUB_TOKEN` chỉ dùng ở server.
- Firmware tích hợp qua `github/GitHubProvider.h`. `configure()`, `tick()` và `snapshot()` gọi trên cùng vòng lặp. `snapshot()` tham chiếu dữ liệu do provider giữ để renderer và REST có thể dùng con trỏ ổn định trong vòng lặp. Provider dùng task FreeRTOS riêng để gọi HTTPS, xác thực hostname và CA ISRG Root X1, có timeout mạng 8 giây và giới hạn body 1024 byte. Refresh sau 20 phút, thử lại lỗi thường sau 60 giây hoặc theo `Retry-After` với 429. Cache RAM giữ lần nhận thành công gần nhất của cùng cấu hình và được hiển thị `Stale` khi có lỗi. Đổi cấu hình loại bỏ snapshot cũ và kết quả truy vấn cũ nếu truy vấn đó vẫn đang chạy. Thiếu một trong hai cài đặt vào Demo.
- Kiểm thử từ thư mục gốc với `source .dev/env.sh && npm --prefix github-proxy test`. 9/9 đạt với fixture, gồm lịch 52×7, padding, streak, biên UTC, cache, lỗi upstream, validation và rate limit.
- Build riêng provider trên PlatformIO với `source .dev/env.sh && pio run -d .dev/github-qa -j 2`, dùng Arduino-ESP32 2.0.17 và ArduinoJson 7.4.2. Log `.dev/logs/github-provider-build.log`. Sketch build gọi đủ ba hàm public của provider. Build riêng dùng 26.792 byte RAM tĩnh và 506.305 byte flash theo báo cáo PlatformIO. Đây là kiểm tra biên dịch/link, chưa đo heap TLS lúc chạy.
- HTTP loopback qua `python3 verification/check_http.py proxy ENDPOINT --fixture-http` đạt 2/2 check với proxy thật và fixture upstream. Log `.dev/logs/github-proxy-http-fixture.log`. Chạy riêng hàm parse C++ trên macOS với ArduinoJson 7.4.2 và đầu ra JSON từ proxy, xác nhận mức màu, tổng, streak, repo null, username, ngày và URL. Mã harness tạm tại `.dev/github-qa/parse-test.cpp`, log `.dev/logs/github-provider-parser.log`.
- Chờ kiểm tra trên ESP32 với endpoint đã cấu hình để xác nhận TLS thật, lấy dữ liệu GitHub thật, trạng thái `live`/`stale`, reconnect và bộ nhớ khả dụng khi đồng thời phục vụ dashboard. Chưa thiết lập Vercel, chưa dùng token thật, chưa upload firmware.
